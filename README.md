# My-Learning

Learning journey and experiments while studying CSE (AI & ML).

This repo is a personal learning log: small scripts, notes, and experiments I create as I work through new topics. It is not a polished library — it is a record of what I am learning and how far along I am.

## Current Focus

Right now I am learning **PyTorch**, working through the fundamentals:

- `01_workflow.py` — a PyTorch end-to-end workflow on a linear-regression dataset: preparing and loading data, train/test splitting, building a model with `nn.Module`, training, inference, and visualization.
- `02_pytorch_classification.py` — neural network classification basics on the scikit-learn `make_circles` toy dataset: tensor conversion, device-agnostic code, and a small binary classifier.

Earlier experiments include a basic HTML/CSS page (`index.html`, `style.css`).
